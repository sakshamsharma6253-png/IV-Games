Quick Queens Guide

What is N Queens?
A classic combinational puzzle that involves placing N chess quuens on an N x N chessboard so that no two queens can attack each other
Problem
Place N queens on an N×N board so no two attack each other.
Attacks
Queens attack along rows, columns and diagonals.
Solver
Try the min-conflicts solver or place queens manually to learn how conflicts arise.
Visualization
Use the visualizer to see conflicts highlighted and solver progress.
