Welcome to IV Games

IV Games is a centeralized, web based gaming hub featuring a collection of classic-mini-games. Play your favorites directly in the browser with instant responsiveness-no downloads or local installations requied.

The Vision

This project was built to demonstrate the power of asynchronous execution and modern web technologies. By running complex logic (like Python and Pygame Modules converted for the web) seamlessly within a lightweight browser envioronment, IV Games bridges the gap between classic programming and modern user expierience.

Behind The Code

Developed by Saksham Sharma, a software developer and BCA graduate from Shree Mahaveer College, Jaipur. This plateform serves as a practical implemantation of software development principals, utilizing clean coding practices, intuitive UI/UX design and algorithmic logic (DSA) to deliver a seamless gaming expierience.
