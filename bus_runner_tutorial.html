Play Guide

Run locally
Download the desktop package and run with Python + pygame, or try the web demo.
Controls
Use arrow keys or on-screen controls to move and dodge obstacles.
Goal
Survive as long as possible and collect points.
Troubleshooting
If desktop build fails, ensure `pygame` is installed and Python 3.10+ is used.
