Bus Runner (Pygame)

The original Bus Runner is a Pygame script that runs on the desktop. Browser porting is possible but not included here.
Download bus_runner.py
Run locally: 
python bus_runner.py
# Requires: pygame (install with `pip install pygame-ce` for Python 3.14)

Notes

This hub embeds the web versions of games you already have in the `web/` folder. If you want Bus Runner playable in the browser, I can port it — that requires a separate effort.
