1.OverView

Welcome to IV Games, a lightweight gaming hub designed for quick, browser-based gaming sessions.All games are completely optimised to run smoothly, supporting offline play with instant responsiveness.

2.Game Guide

Our Catalog features classic and newly enginerred arcade expieriences:

• 3D Bus Runner

A fast paced, high-fidelity infinite running game built on a 3D canvas. Use keyboard arrows to dodge oncoming traffic and secure your high score.

• Ludo

The timeless multiplayer classic, redesigned with a clean and interactive layout. Click straight on your tokens to trigger moves and cycle turns effortlessly, delivering a truly modern and fast-paced gaming experience.

• Chess

A feature-rich local chess simulation bringing the traditional board to your screen. Navigate turns smoothly with interactive drag-and-drop pieces, automated smart timers, and an uncluttered modern layout.

Mini-Sudoko

An elegant and fully responsive Single-Page Sudoku Application (SPA). Features dynamic board scaling for 4x4, 6x6, and 9x9 modes, an intelligent error-checking system, custom modals, and a sleek Neobrutalist aesthetic for an uncluttered user experience.

• Tic-Tac-Toe

Quick match mode against an intelligent AI script or local multiplayer. Perfect for sharp mental breaks.

3. System Requirements

  • Any modern web browser (Google Chrome, Microsoft Edge, Firefox, or Safari).
  • Keyboard input for action games (like Bus Runner).
  • Hardware accleration enabled for optimum 3D rendering.

4. Ad & Monetization Compliance

This plateform follows standard global ad distribution networks. All gameplay data stored locally in your browser cache to maintain data isolation and quick reloading times.
